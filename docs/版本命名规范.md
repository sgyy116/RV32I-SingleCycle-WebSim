# 版本命名规范

沿用现有 `主版本.小版本.修订号` 形式。

- 主版本：不兼容接口或体系结构变化时递增。
- 小版本：新增兼容功能时递增，修订号归零。
- 修订号：修复或界面整理时递增，不改变既有接口。

本次新增术语词典、六类信号配色和静态托管，在 v1.3.1 之后定为 **1.4.0**。编号代表整合内容；只有合入稳定 main 并完成发布步骤后才称为正式发布版。

版本目录使用 `RV32I-SingleCycle-WebSim-vX.Y.Z`。功能分支使用 `feature/*`，修复分支使用 `fix/*`。发布标签使用 `vX.Y.Z`；日期来源资料继续使用 `snapshot/*`，不与同号正式版本混称。已有日期快照更名记录保留在两份版本更新说明中。

本次在 1.4.0 基础上整理已有界面与异常展示，不改变后端协议和指令语义，递增修订号为 **1.4.1**；开发分支 `fix/ui-v1.4.1`。2026-10-07 按用户要求同步 GitHub main，以 `v1.4.1` 标签标记正式发布代码；已有正式标签和 snapshot 标签不移动。
