# RV32I 单周期模型机版本更新说明（具体版）

## 当前最新版本

项目当前最新正式版本为 **v1.3.1**，版本号记录在根目录 `VERSION` 中。`release/v1.3.1` 是该版本的本地 Git 分支，Git 工作树用于隔离和维护代码，不构成另一个版本号。

版本融合关系：**v1.2.0 = v1.1.1 的界面改进 + 0922 原始稿的功能与修正**；**v1.3.0 = v1.2.0 + 0923 原始稿的正确性审计成果**。v1.3.1 在正式 v1.3.0 上完成后续 UI 优化和版本归档，不包含 FPGA 实验分支。

原日期目录 `RV32I-SingleCycle-WebSim-2026-09-22-`、`RV32I-SingleCycle-WebSim-2026-09-23` 已分别更名为 `RV32I-SingleCycle-WebSim-v1.2.0-原始快照`、`RV32I-SingleCycle-WebSim-v1.3.0-原始快照`。两者是**原始来源快照**，并非同名正式工作树。Git 中 `snapshot/v1.2.0-0922` 与 `snapshot/v1.3.0-0923` 标记原始稿；`v1.2.0` 与 `v1.3.0` 标记整理后的正式版。

## v1.1.1：以界面美化为主的前端更新

v1.1.1 的更新依据《具体说明.md》，整体可简单归纳为一次以 AI 辅助美化为主的前端界面优化。重点不在改变 CPU 指令语义，而在统一视觉规范、改善交互和提高数据通路图的可读性。

### 顶部控制区

- 将左侧 R 图标替换为杭州电子科技大学 Logo。
- 移除顶部与左侧重复的示例程序选择框。
- 将单步、单条指令、运行、暂停、复位等按钮的文字改为白色并加粗。
- 统一“速度”文字与控制按钮的视觉风格。
- 为左右历史箭头补充“上一步”“下一步”文字。

### 左侧编辑与指令区

- 调整“汇编代码”“指令列表”标签的间距、边界和字重。
- 在汇编代码示例选择框中增加“自定义”选项；选择后不自动填入初始汇编代码。
- 为指令列表增加滚动滑块。
- 支持传统鼠标滚轮滚动指令列表。

### 中央数据通路图

- 参照既有数据通路图统一部件大小、形状、文字层级和间距。
- 部件名称采用较大的黑色加粗文字，部件说明采用约 0.8 倍字号的深灰色文字。
- 去除部件阴影，减少视觉干扰。
- 按数据通路关系整理连线、箭头和标签的位置。
- 参与当前数据流动的线路使用统一虚线、统一 dash/gap 和流动速度。
- 未参与当前数据流动的线路使用较细实线，并适当提高明度。
- 统一连线旁文字与图例文字的字号和配色关系。
- 将原有加号/减号缩放方式改为进度条式缩放控件，保留“1:1”按钮。
- 保留鼠标滚轮缩放，但将滚轮步进调整为原步进的四分之三。
- 缩放最大值保持不变，最小值不低于原始大小的 0.6 倍。

### 右侧面板与底部状态区

- 统一“指令信号、寄存器、内存、波形”标签的间距、边界和字重。
- 将底部状态栏与页面底部对齐。
- 使底部状态文字字号与左侧标签保持一致。
- 以不同分辨率检查页面布局，避免主要区域被截断或重叠。

### 波形面板

- 当数值信号处于高电平时，将数值文字移到高电平线段下方，避免文字与线重叠。
- 统一增大波形面板内文字，同时保持标题、信号名、周期号、指令名和数值之间的相对层级。
- 控制波形面板最大字号不超过右侧标签字号的 0.9 倍。

### 版本与工程管理

### 条件分支可视化修正

组员指出，前端图中的 `taken` 是条件分支通用判断部件，但原 0922 图和相关命名仍然使用了 BEQ 专用的 `beq_in`、`decoder.beq_out` 和 `w_dec_beq`。本版本进行了以下修正：

- 将输入端改为通用的 `taken.branch_in`。
- 将译码器输出改为 `decoder.branch_out`。
- 将连线改为 `w_dec_branch`。
- 保持高亮规则绑定 `state.control_signals.branch` 和 `state.branch.taken`。
- 经后端核对，当前模拟器已经包含 BEQ、BNE、BLT、BGE、BLTU、BGEU 六种条件判断；本次主要修正的是前端图示和语义命名，避免把通用分支错误表现为仅支持 BEQ。

### 前端实现

- 完成 1.1.1 中杭电 Logo、白色加粗按钮、历史步进文字、左右标签间距等界面调整。
- 增加“自定义”汇编选项，选择后清空编辑器初始内容。
- 为指令列表增加滑块和传统鼠标滚轮滚动。
- 将数据通路缩放控制改为进度条式控件，保留 1:1 和滚轮缩放。
- 调整数据通路高亮线路样式，去除部件阴影并统一虚线流动效果。
- 调整波形数值标注位置和字号，避免高电平文字压在线段上。

## v1.3.0：0923 版正确性审计与验证体系增强

### 后端修复

- 修复 AUIPC 只返回 PC、未加立即数的问题。
- 修复 CSR 指令实际写寄存器但控制信号未显示寄存器写使能的问题。
- 分支 ALU 根据 `funct3` 区分 SUB、SLT 和 SLTU，完整支持六类 RV32I 条件分支。
- 非法及保留编码统一触发非法指令异常，并以 `.word` 形式显示。
- gcc 存在但编译失败时直接返回 gcc 错误，只有 gcc 不存在时才使用内置汇编器。

### 前端数据通路与验证

- `taken` 从 BEQ 专用判据改为由 `funct3`、ZF 和 LT 共同决定的通用条件分支判据。
- 增加 `less` 信号以及分支选择/极性相关连线，调整 `taken` 部件几何形状。
- 修正 PC 目标链及多个恒亮、接反或缺少条件门控的高亮规则。
- 增加点亮契约、正反向高亮断言、波次传播检查和控制流验证夹具。

### 汇编器与测试

- 增加 `li`、`mv`、`nop`、`ret`、`call`、`j`、`la`、`beqz`、`bnez` 等伪指令。
- 支持行内标签、十六进制访存偏移、多种 `jalr` 写法、`fp` 别名和更明确的错误信息。
- 增加独立 RV32I 参考模型差分测试、汇编/反汇编往返测试、非法编码扫描和伪指令端到端测试。
- 0923 版复验结果：模拟器 126 项、汇编器 55 项、差分测试 55/55、往返测试 9/9、综合离线检查 16 步通过。
