# v1.5.0 更新说明

## 布局与交互

三列、上下和单视图按内容视口比例与宽度切换，临界范围设缓冲。顶部速度与历史操作和工作区模式同步换行；平台名称空间不足时提前隐藏。窄屏按钮采用固定文字分组。

编辑器及面板持续挂载，保留撤销栈、光标、标签选择与图形视角。

## 信息显示

缩放、连接、程序状态、周期、PC、指令、波次和异常提示集中到底栏。中等窗口按组分为两行，窄窗口按组换行。连接地址及长指令的完整内容可通过悬停查看。

三列默认展开图例，上下和单视图默认收起。图例空间不足时自动收起，手动展开仍能查看完整内容。

## 构建与目录

Tailwind 配置不再依赖进程启动目录。前端产物由 Python 服务在 8081 提供。

需求草稿、试验过程、旧版报告和一次性补丁移到正式目录外归档。正式目录保留使用文档、当前版本说明、源码、接口约定及测试工具。

布局规则见响应式布局.md，测试范围见验证记录-v1.5.0.md。
