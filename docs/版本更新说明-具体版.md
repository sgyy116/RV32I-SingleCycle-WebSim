## v1.4.1：按具体说明补齐界面与异常展示

最新状态提示修正：首次连接或后端返回明确的缺程序提示时，底栏显示“程序未加载”，状态为 idle，不显示错误颜色；未知消息及编译失败等其他错误继续保留。

1. 保留杭电校徽、白色加粗控制按钮、唯一示例选择、自定义代码、历史按钮文字、指令滚动与自动跟随；左右标签居中、加粗并留边。保留圆框、译码器避让、统一梯形缺口与 src1_rdata 下方标注。
2. 部件名改为纯黑加粗，端口说明采用较小深灰字。波形文字增大、顶部线段数值下移，超过六位的十六进制值显示前四位加省略号。
3. 缩放滑块恢复 0.6～3 倍，保留 1:1；滚轮倍率 1.1125，是历史 1.15 的增量缩小至四分之三。缩放和周期栏按最新反馈共用白色圆角框规范，两端圆润，文字与滑轨适配白底，图区留白取布局文件的背景色。
4. 修正高亮 CSS 对分组的继承影响：流动虚线只施加于连线路径，部件框和箭头不再流动。端口指示点由布局的连线端点生成，只随实际激活连线点亮，不把未选择输入一并点亮。闪烁与流动共用 0.6 秒周期，减少动态效果的系统设置下保持静态高亮。网页与离线高亮导出保持一致。
5. 收起后侧栏占宽为零，仅在图区边缘显示 34px 展开按钮；隐藏组件保留测量宽度和实例，编辑器内容与撤销栈、右栏选项不丢失。
6. 波形移除 PC 和 ALU 的轨迹和选项；其数值仍可在指令信号和数据通路查看。七个布尔信号与 32 个寄存器选项保留。
7. 排查确认不存在独立“异常／中断”触发按钮。异常由 ecall/ebreak/非法指令等触发，中断由计时器和 CSR 开关触发。修复停机锁死剩余动画的问题，并区分 mtvec=0 停机与正常进入处理程序的提示；补播暂停和浏览历史不再解除后端停机保护，防止后续 step 覆盖异常快照。异常往返、mret 和计时器示例以真实后端复验。

操作与排查详情见 `docs/异常与中断使用说明.md`，验证见 `docs/验证记录-v1.4.1.md`。开发阶段未修改 CPU 核心、通信协议或既有标签；本次按用户要求同步 GitHub main 与 v1.4.1 标签，仅推送跟踪的源码、文档和必要资源，不推送构建与测试产物。

2026-10-07 二次修正：左右标签从整组居中改为每项等分剩余导航宽度，减少边缘留白；右侧收起按钮移到左端；图例文案改为“线条类别”。版本号仍为 1.4.1。

版本融合关系：**v1.2.0 = v1.1.1 的界面改进 + 0922 原始稿的功能与修正**；**v1.3.0 = v1.2.0 + 0923 原始稿的正确性审计成果**。v1.3.1 在正式 v1.3.0 上完成后续 UI 优化和版本归档，不包含 FPGA 实验分支。

### 条件分支可视化修正

组员指出，前端图中的 `taken` 是条件分支通用判断部件，但原 0922 图和相关命名仍然使用了 BEQ 专用的 `beq_in`、`decoder.beq_out` 和 `w_dec_beq`。本版本进行了以下修正：

- 将输入端改为通用的 `taken.branch_in`。
- 将译码器输出改为 `decoder.branch_out`。
- 将连线改为 `w_dec_branch`。
- 保持高亮规则绑定 `state.control_signals.branch` 和 `state.branch.taken`。
- 经后端核对，当前模拟器已经包含 BEQ、BNE、BLT、BGE、BLTU、BGEU 六种条件判断；本次主要修正的是前端图示和语义命名，避免把通用分支错误表现为仅支持 BEQ。

## v1.3.0：0923 版正确性审计与验证体系增强

### 后端修复

- 修复 AUIPC 只返回 PC、未加立即数的问题。
- 修复 CSR 指令实际写寄存器但控制信号未显示寄存器写使能的问题。
- 分支 ALU 根据 `funct3` 区分 SUB、SLT 和 SLTU，完整支持六类 RV32I 条件分支。
- 非法及保留编码统一触发非法指令异常，并以 `.word` 形式显示。
- gcc 存在但编译失败时直接返回 gcc 错误，只有 gcc 不存在时才使用内置汇编器。

### 前端数据通路与验证

- `taken` 从 BEQ 专用判据改为由 `funct3`、ZF 和 LT 共同决定的通用条件分支判据。
- 增加 `less` 信号以及分支选择/极性相关连线，调整 `taken` 部件几何形状。
- 修正 PC 目标链及多个恒亮、接反或缺少条件门控的高亮规则。
- 增加点亮契约、正反向高亮断言、波次传播检查和控制流验证夹具。

### 汇编器与测试

- 增加 `li`、`mv`、`nop`、`ret`、`call`、`j`、`la`、`beqz`、`bnez` 等伪指令。
- 支持行内标签、十六进制访存偏移、多种 `jalr` 写法、`fp` 别名和更明确的错误信息。
- 增加独立 RV32I 参考模型差分测试、汇编/反汇编往返测试、非法编码扫描和伪指令端到端测试。
- 0923 版复验结果：模拟器 126 项、汇编器 55 项、差分测试 55/55、往返测试 9/9、综合离线检查 16 步通过。
