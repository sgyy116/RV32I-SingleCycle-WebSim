# RV32I 单周期模型机版本更新说明（具体版）

## 当前最新版本

项目当前最新正式版本为 **v1.2.0**，版本号记录在根目录 `VERSION` 中。`release/v1.2.0` 是该版本的 Git 分支，Git 工作树用于隔离和维护代码，不构成另一个版本号。

## v1.1.0：中心数据通路图基础修正

1. 对中心数据通路导图进行简单修正。
2. 调整部分处理器部件、数据流向和连线的对应关系，使 PC、指令存储器、译码器、寄存器堆、ALU、数据存储器和写回路径的展示更连贯。
3. 修正图面中的基础布局和可读性问题，为后续增加异常、中断和前端交互效果提供较稳定的图形基础。

## v1.1.1：以界面美化为主的前端更新

v1.1.1 的更新依据《具体说明.md》，整体可简单归纳为一次以 AI 辅助美化为主的前端界面优化。重点不在改变 CPU 指令语义，而在统一视觉规范、改善交互和提高数据通路图的可读性。

### 顶部控制区

- 将左侧 R 图标替换为杭州电子科技大学 Logo。
- 移除顶部与左侧重复的示例程序选择框。
- 将单步、单条指令、运行、暂停、复位等按钮的文字改为白色并加粗。
- 统一“速度”文字与控制按钮的视觉风格。
- 为左右历史箭头补充“上一步”“下一步”文字。

### 左侧编辑与指令区

- 调整“汇编代码”“指令列表”标签的间距、边界和字重。
- 在汇编代码示例选择框中增加“自定义”选项；选择后不自动填入初始汇编代码。
- 为指令列表增加滚动滑块。
- 支持传统鼠标滚轮滚动指令列表。

### 中央数据通路图

- 参照既有数据通路图统一部件大小、形状、文字层级和间距。
- 部件名称采用较大的黑色加粗文字，部件说明采用约 0.8 倍字号的深灰色文字。
- 去除部件阴影，减少视觉干扰。
- 按数据通路关系整理连线、箭头和标签的位置。
- 参与当前数据流动的线路使用统一虚线、统一 dash/gap 和流动速度。
- 未参与当前数据流动的线路使用较细实线，并适当提高明度。
- 统一连线旁文字与图例文字的字号和配色关系。
- 将原有加号/减号缩放方式改为进度条式缩放控件，保留“1:1”按钮。
- 保留鼠标滚轮缩放，但将滚轮步进调整为原步进的四分之三。
- 缩放最大值保持不变，最小值不低于原始大小的 0.6 倍。

### 右侧面板与底部状态区

- 统一“指令信号、寄存器、内存、波形”标签的间距、边界和字重。
- 将底部状态栏与页面底部对齐。
- 使底部状态文字字号与左侧标签保持一致。
- 以不同分辨率检查页面布局，避免主要区域被截断或重叠。

### 波形面板

- 当数值信号处于高电平时，将数值文字移到高电平线段下方，避免文字与线重叠。
- 统一增大波形面板内文字，同时保持标题、信号名、周期号、指令名和数值之间的相对层级。
- 控制波形面板最大字号不超过右侧标签字号的 0.9 倍。

## v1.2.0：0922 版正式化与条件分支修正

### 版本与工程管理

- 将 0922 版复制整理为独立的 `release/v1.2.0` Git 工作树。
- 增加根目录 `VERSION` 文件，正式版本号为 `1.2.0`。
- 在 README 和变更记录中补充正式版本说明。
- 保持原始 0922 目录和 1.1.1 目录不修改。

### 条件分支可视化修正

组员指出，前端图中的 `taken` 是条件分支通用判断部件，但原 0922 图和相关命名仍然使用了 BEQ 专用的 `beq_in`、`decoder.beq_out` 和 `w_dec_beq`。本版本进行了以下修正：

- 将输入端改为通用的 `taken.branch_in`。
- 将译码器输出改为 `decoder.branch_out`。
- 将连线改为 `w_dec_branch`。
- 保持高亮规则绑定 `state.control_signals.branch` 和 `state.branch.taken`。
- 经后端核对，当前模拟器已经包含 BEQ、BNE、BLT、BGE、BLTU、BGEU 六种条件判断；本次主要修正的是前端图示和语义命名，避免把通用分支错误表现为仅支持 BEQ。

### 前端实现

- 完成 1.1.1 中杭电 Logo、白色加粗按钮、历史步进文字、左右标签间距等界面调整。
- 增加“自定义”汇编选项，选择后清空编辑器初始内容。
- 为指令列表增加滑块和传统鼠标滚轮滚动。
- 将数据通路缩放控制改为进度条式控件，保留 1:1 和滚轮缩放。
- 调整数据通路高亮线路样式，去除部件阴影并统一虚线流动效果。
- 调整波形数值标注位置和字号，避免高电平文字压在线段上。
