# v1.5.1 更新说明

本版本在 v1.5.0 基础上增加 Ubuntu 服务器部署能力，不改变 RV32I 模拟核心的指令语义。

- 前端 WebSocket 地址改为与页面同源的 `/ws`，HTTPS 页面自动使用 `wss`。
- 编译和加载在用户自己的 WebSocket 会话中完成，不再向浏览器发送服务器上的编译文件路径。
- 服务器模式可将 8080/8081 限定在本机，并关闭 HTTP 编译接口及按文件路径加载入口；会话结束时清理临时目录。
- 提供 systemd 与 Nginx 配置，以及从 GitHub 标签检出、构建和启动的 Ubuntu 操作说明。
- 并发测试脚本先建立全部连接，再集中发起编译请求，记录请求发出时间跨度、编译加载延迟与成功率。

部署操作见 [Ubuntu 服务器部署](Ubuntu服务器部署.md)。本地 Fedora 上使用教学程序完成了 100 条连接同时编译加载并单步的联调；目标 Ubuntu 服务器的性能仍需按部署指南实测。
