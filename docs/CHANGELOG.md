# 变更记录

## v1.5.1

前端改用同源 `/ws` 连接服务器，按页面协议自动选择 `ws` 或 `wss`。编译与加载改在独立 WebSocket 会话中完成，避免向浏览器暴露服务器文件路径。新增 Ubuntu 的 systemd、Nginx 部署配置；服务器模式仅监听本机，并关闭 HTTP 编译及按路径加载入口。新增先建立 100 条连接、再集中发起编译的并发测试脚本与部署说明。

详情见 [v1.5.1 更新说明](版本更新说明-v1.5.1.md)。

## v1.5.0

响应式布局、顶部操作分组、统一底栏与图例默认状态。修复 Tailwind 配置路径问题。正式目录移出需求草稿、试验记录、旧版报告和一次性补丁。

详情见版本更新说明-具体版.md，验证见验证记录-v1.5.0.md。

## v1.4.1

调整侧栏、标签、端口动画和波形显示，修复停机异常及未加载程序状态提示。
