# 响应式前端开发与验证记录

2026-10-09 已整合为本地正式版 v1.5.0，分支 `release/v1.5.0`，目录 `codex_workstation/RV32I-SingleCycle-WebSim-v1.5.0`。正式入口为 http://localhost:8081/ ，运行启动器即可。下文保留 `feature/responsive-reflow` 从 `adba15e` 开始的开发及验证过程；5175 属于开发预览。

## 布局

宽屏采用代码、数据通路、状态三栏。较窄窗口把数据通路放在上方整行，代码与状态在下方并列。窄屏通过“数据通路／汇编代码／运行状态”切换单列工作区。上下布局仅在工作区内部滚动，操作栏与底部状态栏保持可见。

判断依据是浏览器内容视口的有效 CSS 宽高比和宽度；使用整个内容视口的高度，避免顶底栏换行触发反馈。初次打开时，宽度至少 1000px 且比例至少 4:3 采用三栏；不足 800px 采用单列；其他情况采用上下布局。之后使用以下往返阈值：

| 切换方向 | 条件 |
|---|---|
| 三栏 → 上下 | 比例小于 1.30，或宽度小于 960px |
| 上下 → 三栏 | 比例至少 1.36，且宽度至少 1040px |
| 上下 → 单列 | 小于 760px |
| 单列 → 上下 | 达到 840px；满足三栏条件时直接进入三栏 |

跨越多个断点时直接进入合适布局；缓冲区内保留原布局，避免反复跳变。布局内部用 Grid 与弹性宽度连续调整空间，不对整页施加缩放，也不重置数据通路视角。窗口很矮时，工作区内部滚动以保证最低操作高度。

## 状态

同一份编辑器、数据通路和状态面板始终挂载。单列中暂不可见的面板使用 visibility 与 inert 保留测量尺寸，并从交互及辅助技术导航中隐藏。编辑器尺寸改变后重新测量，保留内容、光标和撤销记录。在编辑器或状态面板中操作时拖窄窗口，会继续显示正在操作的工作区。宽屏侧栏折叠偏好独立保留。

器件几何、连线、高亮、波次、编译与仿真协议保持 1.4.1 的实现。

## 预览

## 验证结果

### 独立预览工具栏修复

从项目根目录启动预览时，PostCSS 的 Tailwind 插件未找到前端配置，工具类没有生成，导致校徽显示为原始尺寸、工具栏失去样式。现将 PostCSS 中的配置文件地址固定为相对配置文件的绝对路径，并将 Tailwind 内容扫描设置为相对其配置文件，消除对启动目录的依赖。

新增 `tools/test_reflow_preview.cjs` 直接检查 5175 预览页面。原错误上校徽测量为 474px，检查失败；修复后四种窗口下校徽均为 32×32px，顶栏与按钮尺寸正确，词典、真实单条执行和复位可点击，共五组通过，零运行错误。注入 474px 校徽样式时，同一检查再次失败；新测试页正常打开后完整检查恢复通过。人工查看修复后的 1312×1106 截图。生产构建和 15 项离线检查通过。

执行预览检查前先启动 `node tools/preview_reflow.cjs`。Playwright 由工作站的 ui-validation/node_modules 提供，需通过 NODE_PATH 指定。检查结果在 tools/out/ui-reflow/preview-results.json。

## 2026-10-08 控制栏精简与执行状态合并

按用户确认的方案，600px 及以下窗口固定分组：单步／单条指令／运行在第一行，暂停／复位／术语词典在第二行，校徽位于左侧；按钮只保留文字。速度与历史按钮位于下方，380px 及以下历史按钮整体另起一行。宽窗口保留原有图标及操作方式。

取消图区周期指示条，图区工具条只保留缩放。周期、PC、当前指令统一迁到底栏，连接与程序状态一并保留；波次进度、运行状态和异常／中断提示没有删减。900px 及以下底栏将连接状态与执行位置分行，长指令省略显示并在悬停提示中保留全文。连接地址只在悬停时显示，来自仿真 store 的实际连接配置，不再写死 8080。

验证：生产构建通过；修改前后 15 项离线检查通过；直接预览检查 7/7，覆盖 1920、1312、1024、538、390、360px，窄屏真实单条执行、词典及复位正常；布局回归 5/5、原有回归按最新界面要求修订后 21/21，均零浏览器错误。去重检查临时注入重复状态条后失败，删除后恢复；缩放条圆角检查注入直角样式后失败、移除后恢复。截图与结果在 tools/out/ui-reflow。

### 缩放条整合到底栏

按用户进一步要求，将缩放滑条、倍率及 1:1 按钮迁到底栏，图区不再显示顶部浮动工具条。通过数据通路组件公开的同一组缩放接口调用，保留以中心／鼠标位置缩放、平移后复位以及 0.6–3 倍边界。滚轮改变视角时底栏倍率同步更新。窄窗口底栏自动换行，缩放条排列在执行信息下方；高度继续同步到词典浮层。

验证：生产构建、修改前后 15 项离线检查通过；预览 7/7、布局回归 5/5、界面回归 21/21，零浏览器错误。底栏滑条真实键盘操作更新图形与倍率，1:1 恢复原始 viewBox；完整范围与连续窗口重排保持视角检查通过。临时把实际控件移回图区，同一位置检查失败，按原 DOM 位置恢复后通过。六种预览尺寸无裁切、无横向溢出；查看 390px 截图确认底栏分行。

### 根据窗口比例延后重排，并整理中等窗口底栏

按用户截图反馈，将三栏／上下的判据由仅宽度改为上述宽高比与可用宽度共同判断。1920×1200 和 1280×800 的横向窗口保留三栏，1408×1200 接近方形时进入上下布局；三栏所需的最小宽度仍保留，以免极窄横向窗口把编辑器和状态挤坏。高度变化也会触发布局观察，临界范围继续保留缓冲。

底栏改为两个完整组：缩放＋连接／程序状态，以及周期＋PC＋指令＋波次／异常。大窗口两组同行，1200px 及以下两组各占一行；600px 及以下按组换行。774px 的真实已加载状态下保持两行，波次不再单独挤出第三行。

本轮构建与前后 15 项离线检查通过。预览检查覆盖九种窗口及真实指令操作共 10 项通过；宽高比往返检查覆盖仅改变高度、比例缓冲和最小宽度。将三栏返回比例临时改成 1.30 时同一检查失败，按字节恢复并核对 SHA256，重新构建后验证正常。

恢复正常实现后的布局回归 5/5、原有界面回归 21/21 均通过，零浏览器错误。

### 2026-10-09 顶栏名称与图例的换行处理

平台名称改为按顶栏各组实际测量宽度提前隐藏，取消固定 lg 显示断点造成的一行→两行→一行跳变。名称隐藏后保留不可见测量宽度；校徽与按钮不移动到临时的第二行。空间真正不足以容纳控制按钮时仍采用原有窄屏分组。

图例按图区实际可用宽度测量两条内容行，任一行放不下就自动收起；即使用户之前展开过，拖窄后也执行收起。图例不再因内容换行形成第三条内容行。手动展开仍可查看完整图例，超宽内容保持两行并可横向滚动；隐藏内容保持挂载、不可交互且从辅助技术隐藏。

生产构建和修改前后 15 项离线检查通过；预览回归 12/12，连续 1500→960→1500px 检查顶栏始终单行，图例展开／自动收起／完整内容检查通过。临时强制显示平台名称能捕获换行回退；临时将图例行宽改成 300px 并允许换行也能捕获额外换行，移除变异样式后恢复。布局回归 5/5，零浏览器错误。
