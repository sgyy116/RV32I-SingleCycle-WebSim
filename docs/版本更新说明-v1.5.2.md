# v1.5.2 更新说明

修复 v1.5.1 本地启动时页面不断重连的问题。8081 HTTP 服务新增同源 `/ws`，直接使用同一套 WebSocket 会话处理，不经过本机回环代理；原 8080 独立入口与 Nginx `/ws` 转发保持兼容，服务器模式的路径加载限制、会话隔离和退出清理保持不变。

重新编译和成功加载时清理上一次错误。综合 UI 回归等待 WebSocket 返回的编译结果，不再把“请求已发送”误认为“编译已完成”；新增错误后重试成功的检查及同源入口集成测试。

HTTP 服务清理时主动关闭活动 WebSocket。修正核心关闭命令写入格式，避免正常关闭时因字符串写入二进制管道失败而等待超时强杀；兜底强杀后等待进程回收。

本版不改变 CPU 指令语义，不混入本地未发布的紧凑 UI，也不升级依赖。已知依赖审计告警及 Ubuntu/Nginx 实机验证边界见 [验证记录](验证记录-v1.5.2.md)。已有 v1.5.1 标签保留。
