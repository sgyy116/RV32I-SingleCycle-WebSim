## 环境

Windows、Edge；Node.js 26.3.0、Python 3.12.10、g++ 16.1.0；aiohttp 3.14.1、websockets 16.0。未在 Ubuntu、Nginx、systemd、HTTPS 或移动真机上执行本次验收。本机并发不代表目标学校服务器性能。

## 修复前后对照

- 同源入口回归在原实现上出现 `/ws` HTTP 404；修复后在 HTTP 端口真实完成握手、编译、加载、单步，独立 8080 入口仍可用。
- 错误源码后合法重试的 UI 断言在原实现上捕获残留 errorMessage；修复后清空旧错误，仍保留真实编译失败的错误状态和提示。
- 活动会话停服回归先捕获异常关闭码 1006；修复后主动发送 1001，并清空会话。
- 核心正常关闭回归先捕获子进程尚未正常退出；修复字节编码后退出码为 0，强杀兜底也等待回收。
- 只读代码评审复核通过；未通过放宽断言或改掉错误预期来掩盖失败。
