## 验证

修改前后运行 `python -B tools/check_all.py --no-regen`，15 项必须全部通过，跳过不算通过。首次检出缺少状态夹具时，先运行不带 --no-regen 的完整检查生成夹具。

修改 frontend/src 后运行 `npm --prefix frontend run build`，正式页面 Ctrl+F5 刷新。

浏览器验证工具：tools/test_ui_v1_4_1.cjs、tools/test_ui_reflow.cjs、tools/test_reflow_preview.cjs。环境与正式页面测试参数见验证记录-v1.5.0.md。

同源入口回归：`python -B backend/test/test_same_origin.py`，覆盖 HTTP 升级、真实编译/单步、会话隔离、退出清理、服务器模式限制和独立 WebSocket 兼容。综合 UI 检查前生成高亮 SVG：`node tools/hl_preview.mjs tools/out/_hl_states.jsonl 1`。

匿名会话隔离回归：`python -B backend/test/test_sessions.py`、`node tools/test_session_frontend.cjs`。覆盖双入口并发、寄存器/内存/断点隔离、拒绝跨会话路径加载、重复加载进程回收、运行与查询同步、取消编译后的目录清理，以及重连时清除失效状态。每条连接一个实验，重连需重新加载；详见 PROTOCOL.md。HTTP 编译 API 在本地模式仅提供结果预览，不再返回文件路径；需要加载时统一使用 WebSocket `load`。

## 已知限制

网络检测与实验排队：底栏“网络检测”手动测量延迟、上传和下载，可取消；名额不足时显示前方人数，并支持退出、重新加入与空位自动准入。回归命令为 `python -B backend/test/test_access_services.py`、`node tools/test_network_frontend.cjs`、`node tools/test_session_frontend.cjs`、`node tools/test_access_ui.cjs`（浏览器回归需要外部 Playwright 环境）。默认活动上限 20、等待上限 100、空闲回收 1800 秒，配置和限制见 PROTOCOL.md；100 人为建设目标，目标服务器容量仍需压测。单进程内共享队列，当前不支持多副本全局排队。

连接稳定性回归：`node tools/test_websocket_lifecycle.cjs`。覆盖报错后防重复连接、旧消息隔离、失败退避、握手超时和退出定时器回收。排队通知仅在位置或容量信息变化时发送；固定五人依次加入场景从 15 次通知降为 5 次，准入与位置更新保持原语义。

已验证 Windows Edge。Firefox、Safari 和移动真机尚未验证。构建仍提示主包超过 500kB。
