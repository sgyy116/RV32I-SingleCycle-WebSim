# RV32I 单周期模型机版本更新说明

## 版本关系

当前最新正式版本是 **v1.3.1**。`release/v1.3.1` 是该版本的本地 Git 工作树分支；Git 工作树不是独立版本。v1.2.0 融合 v1.1.1 与 0922 原始稿，v1.3.0 在 v1.2.0 基础上融合 0923 原始稿。

原 `RV32I-SingleCycle-WebSim-2026-09-22-`、`RV32I-SingleCycle-WebSim-2026-09-23` 两个日期目录，分别更名为 `RV32I-SingleCycle-WebSim-v1.2.0-原始快照`、`RV32I-SingleCycle-WebSim-v1.3.0-原始快照`。后缀“原始快照”表示其为正式版的来源资料，而非另一个同号正式版。

## 版本演进

### v1.1.0：中心数据通路图基础修正

对中心数据通路导图进行基础整理，修正部件关系、连线位置和整体展示效果，使处理器执行路径更清晰、图面更易读。

### v1.1.1：前端界面美化与交互优化

参照《具体说明.md》对页面进行集中优化，可概括为一次以 AI 辅助美化为主的前端表现层更新：完善顶部控制区、左右侧栏、底部状态栏、数据通路图、缩放控件和波形面板的视觉层级与交互细节。

### v1.2.0：正式化与条件分支语义修正

- 将 0922 版整理为正式版本，并建立 `release/v1.2.0` Git 工作树。
- 将数据通路图中的 `taken` 从 BEQ 专用表达改为通用条件分支表达，覆盖 BEQ、BNE、BLT、BGE、BLTU、BGEU。
- 移植并落实 1.1.1 的主要界面优化，包括杭电 Logo、自定义汇编选项、指令列表滚轮/滑块、数据通路缩放滑块和波形文字避让。
- 增加条件分支、前端图语义、布局、高亮和波次检查，确保可视化结果与后端状态一致。

### v1.3.0：0923 正确性审计与验证体系增强

- 修复 AUIPC、CSR 写回、非法编码和 gcc 编译错误回退等后端问题。
- 将条件分支实现和 `taken` 数据通路扩展为 BEQ、BNE、BLT、BGE、BLTU、BGEU 六类分支。
- 补全微型汇编器的伪指令、标签、十六进制偏移、`jalr` 写法和输入校验。
- 增加独立参考模型差分测试、汇编/反汇编往返测试、非法编码扫描以及前端高亮/波次综合验证。
- 更新交付模拟器、开发文档、修复报告和高亮契约。

### v1.3.1：界面整理与版本归档

- 去除顶部控制按钮的悬停解释；调整数据通路图的 0/1 标识、译码器与 f3 标签、ADD/ALU 形状和 `src1_rdata` 标注。
- 将缩放控件与悬浮指令状态放在一起，底栏贴合视口底部；左右侧栏支持收起，窄窗口默认收起。
- 在本地 Git 中分别保留 1.1.1、0922、0923 原始快照，以及正式 1.2.0、1.3.0、1.3.1 的提交与标签；未合入 FPGA 实验分支。
