## 真实浏览器检查

脚本 `tools/test_ui_v1_4_1.cjs` 使用工作站已有 Playwright 驱动 Microsoft Edge，连接本版本真实 Python 中间层和 C++ 核心，不用模拟响应。测试使用独立 18080/18081，浏览器内映射 WebSocket 测试端口；不停止用户正在使用的 8080/8081 服务。脚本关闭自己的浏览器和服务。

10 组功能检查及 6 种窗口检查通过，浏览器运行错误为 0：

- 方向键可将缩放推到 3 倍或 0.6 倍，1:1 恢复原 viewBox。
- 缩放与周期条的背景、圆角、字色一致；留白与图纸背景一致。
- 左右收起后占宽为零，只留 34px 展开按钮。代码、撤销、右侧当前标签、信号选择器及已选寄存器保持。
- 波形不可再选 PC/ALU，RegWrite、TRAP 和寄存器仍可用；80000000 显示为 8000…。
- 实线部件框无动画；端口与线共用周期。逐一核对实际激活连线的端口，无误亮或漏画；系统减少动态效果时端口停止闪烁。
- 离线高亮 SVG 有激活端口；不带 CSS 的静态参考 SVG 不显示未激活端口。
- 单独执行 ecall，后端停机后仍能逐波完成，完成后按钮禁用且周期不增加；横幅明确表示 mtvec=0 停机。
- 停机后自动补播、暂停、单步补完、翻历史，均不解除后端停机保护；异常快照与寄存器值保留，复位后才能重新执行。
- 异常往返最终 a0=2、a1=99；计时器例出现原因码 0x80000007，t3 和 a1 等于实际中断次数并正常结束。

## 回归检查的有效性

先在未修改实现上运行本轮 UI 脚本：缩放上限、工具条、侧栏、波形选项、部件虚线和停机动画的 6 个检查失败；异常往返与计时器例原本通过。实现后原检查转绿。

补充 SVG 检查时，先观察到离线导出丢失端口高亮、静态 SVG 默认显示黑色端口点，再分别修复类名映射和默认 opacity，原检查转绿。测试脚本等待侧栏展开宽度完成，避免将过渡动画中暂不可见误判为状态丢失；Naive Slider 不支持 Home/End，边界测试使用它实际实现的方向键。

独立只读审查发现补播中暂停会把 halted 展示状态改为 paused，继而允许向已停机核心发送 step。先新增真实浏览器路径并复现失败，再让停机判定同时保留最后执行快照的 halted；暂停不解除停机、step 拒绝已停机执行。随后复验补播、暂停、历史浏览和复位路径。

修订后独立只读复审无新的 Critical／Important／Minor 发现；主代理随后运行完整 UI 脚本，16 组检查全部通过、无浏览器错误。审查本身未运行测试，不能代替上述实测。

## 保留的限制

- npm ci 报告现有依赖中 13 项风险（3 moderate、10 high）；本轮锁定原依赖，不擅自升级或 npm audit fix --force。需要另做依赖升级与安全复验，不能据功能测试声称没有安全风险。
- 生产构建主 chunk 超过 500kB；来源版本的色盲配色和灰度可区分性限制仍在。
- 寄存器波形独立自动缩放，不代表电压或可跨行比较的绝对幅值；波次是教学动画，不是 FPGA 采样。
- 本地修订完成不代表发布，不合入 main、不推送 GitHub、不移动旧标签。

## 复验命令

在仓库根运行 `python -B tools/check_all.py`、`node tools/hl_preview.mjs tools/out/_hl_states.jsonl 1`、`npm --prefix frontend run build`。

浏览器脚本需要 Node 可找到 Playwright。本工作站可先设置 PowerShell 环境变量：

```powershell
$env:NODE_PATH = 'C:\Users\point\projects\计算机项目相关\codex_workstation\ui-validation\node_modules'
node tools/test_ui_v1_4_1.cjs
```

其他机器自行提供 Playwright 与 Edge 路径（可用 EDGE_PATH 环境变量），不将浏览器测试依赖加入运行时依赖。
