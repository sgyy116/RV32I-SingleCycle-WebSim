# 响应式布局

## 工作区

采用浏览器内容视口的 CSS 宽度和宽高比。首次打开：

- 宽度至少 1000px、宽高比至少 4:3：三列。
- 宽度不足 800px：单视图，通过标签切换。
- 其余情况：数据通路在上、代码和状态在下。

连续调整窗口时设置缓冲：

| 切换 | 条件 |
| --- | --- |
| 三列 → 上下 | 宽度小于 960px，或宽高比小于 1.30 |
| 上下 → 三列 | 宽度至少 1040px，且宽高比至少 1.36 |
| 上下 → 单视图 | 宽度小于 760px |
| 单视图 → 上下 | 宽度至少 840px，符合三列条件时直接进入三列 |

编辑器、撤销记录、面板选择和数据通路视角在重排时保留。顶部和底栏固定，工作区内部滚动。

## 控制栏

三列时顶部单行；上下和单视图时，速度与历史操作同步移到下一行。平台名称空间不足时隐藏。600px 及以下按按钮分组排列。

底栏集中显示缩放、连接、程序状态、周期、PC、指令、波次和异常。1200px 及以下固定分为两个信息组；600px 及以下按组换行。长指令的完整内容可通过悬停查看。

## 图例

首次打开及布局切换后，三列默认展开，上下和单视图默认收起。同一模式下允许手动展开或收起。图区宽度不足时自动收起；手动展开保持两条内容行，超宽内容可横向滚动。
