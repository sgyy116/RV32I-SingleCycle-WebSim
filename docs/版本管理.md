## 日常开发

main 表示最近一次通过验证并合入的稳定代码。新增功能从 main 建 `feature/*`，修复建 `fix/*`。本次只在功能工作树整合，main 中其他未提交改动继续独立保留。

提交前核对 `git status --short`、`git diff --check` 和差异内容；运行相关测试、`python -B tools/check_all.py` 和 `cd frontend && npm run build`。后端改动要重新编译 C++ 核心。依赖、dist、build、tools/out、测试 bin 与缓存由 .gitignore 排除。

版本号同时记录在 `VERSION`、`frontend/package.json` 和锁文件根包字段；更新两份版本说明与 CHANGELOG。前端 SVG 参考图由当前布局重新生成。

## 发布

本地整合完成不等于 GitHub 发布。核对并合入稳定 main 后，复验发布提交，再建立不可移动的 `vX.Y.Z` 标签。已有 v1.1.0～v1.3.1 和 snapshot 标签不改写；本次不生成同号新标签覆盖旧历史。

推送时先检查 `git branch -vv`、`git status` 和 `git remote -v`，然后显式选择 main 和本次版本标签。不要使用 `git push --all`；FPGA 实验分支继续单独维护。推送或合入须符合用户当次任务范围。

只在确需并行维护旧版时保留 release 工作树。工作树是隔离检出，不是额外版本号；清理前先确认内容已提交且正式标签仍保留。
