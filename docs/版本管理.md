# 版本管理

主库：https://github.com/sgyy116/RV32I-SingleCycle-WebSim

当前正式版为 v1.5.1，发布在 main 并使用标签 v1.5.1。v1.5.1 在 v1.5.0 基线上新增 Ubuntu 服务器对接、部署配置和集中编译并发测试。

- main 保存远端稳定代码；feature/* 用于功能开发，fix/* 用于修复，release/* 用于版本整合。
- 版本号同步维护 VERSION、frontend/package.json 和 package-lock.json 的根包字段。
- 更新 CHANGELOG 与版本更新说明，提交前检查差异、构建和测试。
- 发布标签使用 vX.Y.Z，已有标签不移动。
- 推送、远端发布和部署须获得用户授权。推送显式指定分支和标签，不使用 --all 或强制推送。
- 本地 main 的其他未提交改动与旧版目录独立保留，不直接覆盖。

## 正式目录

保留运行文件、源码、使用文档、当前版本说明、接口约定和验证工具。需求草稿、临时试验、旧版验证报告、一次性补丁及测试截图在正式目录外归档；不作为正式源码提交。

依赖、构建产物、测试输出和缓存由 .gitignore 排除。源码首次构建步骤见 README。
